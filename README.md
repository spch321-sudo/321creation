## xz1103（2026-11-03）小智最新功能：回答對象、回答長度五段、讀者資料
- 從《321互動聖經》v2.57.2 的小智複製：**回答對象十種**（慕道友另有六種信仰背景）、**回答長度五段**（極短／短／中（預設）／長／極長，舊的簡要／適中／詳細設定自動遷移）、**讀者資料**（多份、12 歲以下只送暱稱）、每個對象 20 題範例問題。繁／简／English（index／sc／en）三個入口都有。

- 實作：新增共用套件 `xz2.js`；GXR 補件裡舊的對象／三段長度改接 XZ2，避免長度送兩次。SW 版本加尾碼 `-xz1103`，`xz2.js` 進預快取。

## v1.5（自動更新 AU）（版本 202611031200-vp1023-gx1103-co1-xz1103-au1103）
- **空閒自動套用**：原本偵測到新版只出現頂端更新條、要按才換，而且頁面沒有註冊 Service Worker 的更新機制、更新時會清掉整個網域的快取。現在偵測到（開啟後、回到前景、每 30 分鐘）就在空閒時自動換新，不必按；朗讀、小智回答、輸入框有內容、共讀、面板開著時只顯示更新條，忙完自動套用；同一版只自動重整一次，再失敗清自家快取硬更新一次，仍失敗只留更新條。
- 「我的」頁新增「版本與更新」卡：版本號、檢查更新（有即時回饋）、強制更新。繁／簡／EN 三個頁面都補。
- sw.js：HTML／JS／JSON 網路優先、updateViaCache:none、只清自家 wanxiang- 前綴的快取（原本會刪掉同網域其他 App 的快取）、新 SW 啟用時通知頁面。

## v1.5（互動聖經標準補件 GXR）（版本 202611031200-vp1023-gx1103-co1）
- **畫線面板補齊**：原本只有 8 色、範圍 ±、默想、儲存／問小智／朗讀／刪除畫線／關閉。現在多了「整節」「整段」一鍵畫完、🖼 做成美圖（直接開美圖工作室，帶著畫線的句子與默想）、複製、分享、朗讀這句、從這句朗讀下去。繁／簡／English 三個入口頁都有。
- **小智**：十種回答對象（成人、青少年、兒童、慕道友、長輩、單親、單身、父母、夫妻、牧者）、回答長度（簡要／適中／詳細；切換長度會用新長度重新回答）、依對象列出追問、範例問題跟著對象換、新提問時舊回答自動收合、回答滿版、「A」字級鈕。（原有的截斷自動接續、收藏、分享、做成美圖、朗讀、刪除照舊。）「我的」頁新增「小智與美圖」卡：對象、長度、美圖工作室、我的作品。
- **朗讀**：多音字修正（PRON321：重生、長老、應許、傳道、撒但…依整詞與上下文）、括號裡只有經文出處不唸、表情符號不唸、背景播放（Media Session 鎖屏控制＋螢幕不休眠）、浮動控制列（暫停／繼續／停止）、頂列 🔊 整頁跟讀、每個小標題旁 🔊 從這一段讀下去。
- 實作：新增獨立補件 gxr（放在各入口頁內），其餘程式只加幾個掛點；自己的設定存在 localStorage `gxr_creation`，不動原有資料。
