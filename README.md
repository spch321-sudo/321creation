## 202611031200-vp1023-gx1103-co1-xz1103-au1103-xzm1103-h12-rf1105（互動聖經 v2.58.3–v2.64.1 功能移植・試點）
- **小智引導禱告**：系統提示不再要求「寫一段禱告／最後以禱告結束」，改為「引導禱告」——不替讀者禱告、不把讀者名字寫進禱告，只邀請讀者用自己的話向神禱告；只有明確要求時才寫禱告文（「幫我寫一段禱告」這類範例題照舊）。繁／简／英三語，五段長度與兒童對象的舊禱告結尾已改。
- **小智誠實與危機提示**：系統提示加「誠實、不編造經文與原文字義、爭議議題並陳、AI 不是牧者／醫生／律師」；讀者提到自殺、自傷時，先顯示固定的求助卡（台灣 119／110／1925／1995／1980，**專線號碼請牧者核對**，簡體與英文版為通用提醒），不把求助卡送進 AI 的上文；讀者資料備註送出前去掉電子郵件、網址與長串數字。
- **原文字義**：經文引用（單元裡的經文方塊）的畫線面板新增「🔍 原文字義」：選字面板（點一字、再點一字選到那裡，或查整句／整段）→ 帶進小智，系統提示補上固定回答結構（原文、這節的用法、其他用法、321 應用）並要求誠實標明把握程度。
- **美圖版面可讀性**：範本輔助色對比 ≥4.5:1；相片上的遮罩依上／中／下三段亮度自動加深；放不下時在預覽下方提醒；新增「✨ 一鍵調整」自動挑尺寸與字級；有相片的卡片輸出 JPEG（.92）。
- **朗讀升級**：音檔存手機（Cache「tts-audio」，300 段上限，同一段不再重抓）、雲端連不上時第一段與重試改快速模式並暫停 20 秒直接用裝置語音、看門狗依實際長度保底續播、鎖屏／耳機上一段下一段、浮動控制列新增睡前定時（15／30／60 分，淡出後停）。（語速三檔原本就有。）
- **載入速度與離線**：sw.js 網路優先加 1 秒競速（慢網路先用快取）；頁面閒置時預存本語言的展館單元與講章（約 3–6MB，省流量／2g 不預存），離線也能讀沒看過的展館；Google 字型改為不擋畫面。
- 版本 `-rf1105`；`xz2.js` 加入引導禱告／誠實／危機／字義函式。宿主 IIFE 內只加了小段掛鉤（`GXR.sysExtra(text)`、畫線面板字義按鈕、危機卡訊息、朗讀快取／看門狗）。
